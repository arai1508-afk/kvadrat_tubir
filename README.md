# 📐 Kvadrat Tubir (Квадрат Түбір) - Математикалық Ойын 🎮

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

Оқушылар мен студенттерге математикалық квадрат түбірді жылдам есептеуді үйрететін интерактивті онлайн ойын.

---

## 📌 Жобаның Мүмкіндіктері
- 🎮 **Интерактивті Ойын:** Логикалық сұрақтар мен визуалды суреттер.
- 🎵 **Аудио эффектілер:** Дұрыс/бұрыс жауаптарға арналған дыбыстар (`audio.js`).
- 📊 **Нәтиже Мониторингі:** `result.html` арқылы ойын аяқталғандағы ұпайларды көрсету.
- 🎨 **Заманауи Дизайн:** Ыңғайлы және анимациялық интерфейс (`style.css`).

---

## 📁 Жоба Құрылымы
```
kvadrat_tubir/
├── index.html         # Басты бет
├── game.html          # Ойын процесі
├── result.html        # Нәтиже тақтасы
├── questions.js       # Сұрақтар базасы
├── audio.js           # Дыбыстық эффектілер
├── style.css          # Дизайн және стильдер
└── images/            # Ойын суреттері
```
